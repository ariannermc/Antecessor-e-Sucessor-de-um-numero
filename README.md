# Antecessor e Sucessor de um Número
 
> Calcula e exibe o antecessor e o sucessor de qualquer número digitado pelo usuário.

---

## Conceito
 
- **Antecessor:** é o número imediatamente anterior. Ex: o antecessor de 10 é **9**
- **Sucessor:** é o número imediatamente posterior. Ex: o sucessor de 10 é **11**

---

## Funcionalidades
 
- O usuário digita qualquer número inteiro
- Exibe o antecessor (número - 1)
- Exibe o sucessor (número + 1)
- Cálculo feito por um método separado (`calculo`), deixando o código organizado
  
---

## Como usar
**Pré-requisito:** Java instalado. </br>
Verifique com:
```bash
java -version
```
 
1. Clone o repositório:
```bash
git clone https://github.com/ariannermc/Antecessor-e-Sucessor-de-um-numero.git
cd Antecessor-e-Sucessor-de-um-numero
```
 
2. Compile o arquivo:
```bash
javac AntecessorSucessor.java
```
 
3. Execute o programa:
```bash
java AntecessorSucessor
```
 
4. Digite o número quando solicitado:
```
Digite um número: 7
O antecessor do número é: 6
O sucessor do número é: 8
```
